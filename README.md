# MIZRACH PINAZ — Band Homepage

A single-page promotional website for MIZRACH PINAZ, a slow-rock band. The design combines a dark concert aesthetic, warm orange accents, animated atmospheric effects, band information, and responsive sections for music, tour details, gallery content, and booking.

## Highlights

- Responsive single-page layout built without a framework
- Custom visual system with CSS gradients, glow effects, motion, and typography
- Band-focused sections for identity, music, tour information, gallery content, and contact/booking
- Mobile-aware layout and navigation
- Self-contained static site that can be opened directly in a browser

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: Cinzel and Poppins

## Run locally

Open `index.html` in a modern browser. For the most reliable local experience, serve the folder with any static HTTP server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project structure

This is intentionally packaged as a compact static website. The main page and its styles, scripts, audio references, and visual sections are contained in `index.html`.

## What this demonstrates

This project demonstrates practical frontend work: turning a visual direction into a responsive interface, organizing a long-form landing page, creating atmosphere with CSS rather than heavy dependencies, and keeping the experience usable across screen sizes.
